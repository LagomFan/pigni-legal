1. 接受协议

下载、安装或使用猪妞，表示你已阅读并同意本协议和《隐私政策》。若你不同意，请停止使用相关功能。涉及相机、语音、第三方 AI 或云备份时，App 仍会按功能另行请求权限或确认。

2. 服务内容

猪妞提供个人记账、日历与图表、AI / OCR 候选账单、账本分析、导入导出、可选备份和会员功能。具体能力以当前版本和购买页面为准。

AI / OCR 只提供候选结果或辅助分析，可能存在遗漏、重复或错误。你应在写入正式账本前确认；重要账务以银行、支付平台和正式票据为准。

3. 账号、设备与数据责任

App 以本机数据为主。你应妥善保管设备、Apple ID、备份文件和 AI 服务密钥，并在换机、卸载或清除数据前完成所需备份。

你应确保录入、上传、导入或交由 AI 处理的内容来源合法，并已取得处理他人个人信息所需的授权。

4. 第三方 AI 与外部服务

你可以使用 App 提供的阿里云百炼、DeepSeek、智谱开放平台、Kimi 开放平台、SiliconFlow 或火山方舟官方 API 地址预设，也可自带服务地址、模型和 API Key。预设不包含开发者账号或 Key，不会自动启用任何用户数据授权，也不会自动发送数据。第三方服务的可用性、准确性、费用、配额、内容规则和数据处理受其条款约束。
